# 画像素材

GPT Imageの組み込み画像生成で制作した、冒険図鑑風の恐竜と背景です。

- 恐竜の成長5段階、図鑑8種類、小物3種類、背景4種類。
- 恐竜は目を大きくしすぎず、鱗や角、背中の板などの特徴を強調。
- 透過素材はアルファを保ったWebP。背景もWebPにして通信量を抑制。
- 元の素材シートから等分して書き出しています。
- `sw.js` の事前キャッシュに全素材を登録しています。
- 画像内に文字は入れず、問題・ヒント・操作の文字はHTMLで表示します。

生成プロンプトは `prompts.txt` に記録しています。

## 化石とごほうび素材（v8）

- 化石8種：`fossil-steg`、`fossil-tri`、`fossil-anky`、`fossil-para`、`fossil-brachio`、`fossil-ptera`、`fossil-spino`、`fossil-rex`。砂色の石灰岩にアイボリーの骨格を描いた、400×400pxの不透明WebPです。
- 小物8点：`gold-egg`、`medal-bronze`、`medal-silver`、`medal-gold`、`chest-open`、`stopwatch`、`flag`、`map`。314×314pxの透過WebPです。
- 既存の `rex.webp` と `treasure.webp` を画風・宝箱の形の参考として、GPT Imageの組み込みツールで制作しました。
- 各マスを正方形に保つため、素材シートは4列×2段・2:1の横長で制作し、1枚ずつ切り出しています。化石は4分割しても各かけらに骨が見えるように配置しています。
- 小物は輪郭を含む全アルファ領域を縦横72%以内に収め、四辺に44px以上（約14%）の完全透明な余白を設けています。
- メダルは銅を共通の形の参考にして銀・金の金属色へ調整し、切り出し範囲と表示上の大きさをそろえました。開いた宝箱は既存の木と真ちゅうのデザインにそろえています。
- 全16点を `sw.js` の `CORE` に追加し、キャッシュ名を `v8-fossil-art` に更新しています。
