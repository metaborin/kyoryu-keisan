# きょうりゅう けいさん

小学1年生向けの、恐竜を育てながら10までのたし算・ひき算を練習するWebアプリ(試作版)。

遊ぶ: https://metaborin.github.io/kyoryu-keisan/

## アプリとしてインストール(PWA)

Chromebookでページを開き、アドレスバー右端のインストールアイコン(またはメニュー︙ →「キャスト、保存、共有」→「ページをアプリとしてインストール」)を選ぶと、ランチャーから開けるアプリになります。一度開けば、インターネットにつながっていなくても遊べます。

更新時は `sw.js` の `VERSION` を上げてください。

## ステージ

| エリア | ステージ | 内容 |
|---|---|---|
| ジャングル | 1 いくつと いくつ / 2 たしざん | 10の合成・分解、10までのたし算 |
| かざん | 3 ひきざん / 4 0の けいさん | 10までのひき算、0を含む計算 |
| うみ | 5 3つの かず / 6 くりあがり | 3口の計算、くり上がりのあるたし算 |
| こおりの くに | 7 くりさがり / 8 おおきい かず | くり下がりのあるひき算、何十・2けたの計算 |

各ステージを初めてクリアすると恐竜図鑑に仲間が加わります。ホームの「おうちのかたへ」を長押しすると、記録と設定の画面が開きます。
