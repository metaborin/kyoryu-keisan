# きょうりゅう けいさん

小学1年生向けの、恐竜を育てながら10までのたし算・ひき算を練習するWebアプリ(試作版)。

遊ぶ: https://metaborin.github.io/kyoryu-keisan/

## アプリとしてインストール(PWA)

Chromebookでページを開き、アドレスバー右端のインストールアイコン(またはメニュー︙ →「キャスト、保存、共有」→「ページをアプリとしてインストール」)を選ぶと、ランチャーから開けるアプリになります。一度開けば、インターネットにつながっていなくても遊べます。

更新時は `sw.js` の `VERSION` と、`index.html` の `style.css?v=` `app.js?v=` の番号を上げてください(GitHub Pages のキャッシュで古いファイルが使われるのを防ぎます)。

## ステージ

| エリア | ステージ | 内容 |
|---|---|---|
| ジャングル | 1 いくつと いくつ / 2 たしざん | 10の合成・分解、10までのたし算 |
| かざん | 3 ひきざん / 4 0の けいさん | 10までのひき算、0を含む計算 |
| うみ | 5 3つの かず / 6 くりあがり | 3口の計算、くり上がりのあるたし算 |
| こおりの くに | 7 くりさがり / 8 おおきい かず | くり下がりのあるひき算、何十・2けたの計算 |

各ステージを初めてクリアすると恐竜図鑑に仲間が加わります。ホームの「おうちのかたへ」を長押しすると、記録と設定の画面が開きます。

## 画像素材

GPT Imageで制作した冒険図鑑風の恐竜・成長段階・4つの背景・アプリアイコンを使用しています。素材と生成プロンプトは `assets/art/` にあります。画像はWebPで軽量化し、オフラインでも使えるよう事前キャッシュしています。

## くりかえし あそぶ しくみ

- ステージごとに3つのあそびかた:ぼうけん(10問・星とじこベスト)、きょうりゅうレース(勝つとライバルが強くなり、負けると弱くなる)、60びょうチャレンジ(最高記録)。レースと60秒はぼうけんを1回クリアすると開放。
- 毎回たからばこからかせきのかけら(8種×4こ=32こ)。どのステージでも集められる。
- 同じステージを遊んだ回数で、どう(3回)・ぎん(10回)・きん(25回)のくんしょう。
- 日替わりの「きょうのミッション」3つ。ぜんぶ達成でたからばこがもう1こ。
- ぼうけん・レースでは「えらぶもんだい」(たまごから選ぶ)と「きんのたまごもんだい」が混ざる。
- 図鑑の仲間を「あいぼう」にすると、問題の画面でいっしょにいてくれる。
